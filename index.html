☁ Cloud Sync (JSONBin)

📖 User Guide

Here is everything you need to know about navigating and managing your OC codes.

🚀 First Time Use

Create a bin at jsonbin.io. Then get the keys in the bin.

🎛️ Control Panel (Menu)

To access the menu panel, click "Unfold Menu 🔽". The menu consists of the total OCs indicator, Cloud Sync panel, filters for easier search, OC code edit panel, and a theme UI tweaks panel. On top of the Control Panel (Menu), is a search box to search for a specific OC.

➕ Add Your OC Codes

Unfold the menu, scroll down, and click "+Add New OC" and paste your online/offline code there. You can also add the OC design version, OC category, and OC tags.

✏️ Edit OC Codes

Normal UI: Click "Edit" button.
Compact UI: Click "⚙️ Option 🔽" to open the edit menu.

☑️ Edit OC Codes Simultaneously

Click a checkbox on the side of the OC name to select the OC you want to edit. Unfold the menu and click "Bulk Edit Selected".

🗑️ Delete OC Codes

I think you got this one.

🎨 UI Tweaks

To customize the theme color, choose "🎨Theme Settings". To customize the UI layout, choose "📐UI Layout".

☁️ Save/Load Data

In the Cloud Sync panel, click "Push⬆️" to save your data to your bin. To load data from your bin, click "Pull⬇️".
